# HydroLab 原型交互规范

> 状态：Confirmed  
> 原型基线：`apps/web/src/App.tsx`  
> 目标：冻结后端接入必须保持的页面语义，不规定具体视觉实现。

## 1. 产品边界

平台没有 Project 概念。用户从全局资源流完成：

```text
数据 → 模型代码 → 实验 → Run → Checkpoint / 结果 → 对比 / 导出
```

主导航：运行中心、数据、模型代码、实验、Checkpoint、结果与对比。辅助入口：权限与分享、运行环境。

## 2. 全局交互约定

### 2.1 资源版本

- DatasetVersion、CodeVersion、ExperimentVersion、RuntimeEnvironmentVersion、Checkpoint 和 ResultArtifact 一旦进入可用状态即不可原地覆盖。
- 修改会创建新版本，并保留来源版本、操作者、时间、说明和内容摘要。
- 实验和 Run 锁定精确版本 ID，不能只保存资源名称。

### 2.2 可见性与分享

- 所有资源默认私有。
- 所有者可在资源详情创建有期限只读链接。
- 链接访问者只能查看创建链接时锁定的不可变版本及被允许的产物。
- 链接不能派生、修改、启动 Run 或继续访问后续新版本。
- 所有者可以提前撤销；服务端记录访问次数和最后访问时间。

### 2.3 异步操作

上传、URL 下载、数据扫描、代码扫描、环境构建、Run、绘图和导出均为异步操作。统一状态：

```text
PENDING → QUEUED → RUNNING → SUCCEEDED
                    ├──────→ FAILED
                    └──────→ CANCELLED
```

页面必须显示任务状态、阶段、时间、可重试性和错误摘要，不以长时间 HTTP 请求等待完成。

### 2.4 列表与错误状态

每个列表具备 loading、empty、error、ready 四态。服务端列表支持游标分页、搜索、结构化筛选和稳定排序。错误返回可展示的摘要、稳定错误码与 request_id。

## 3. 运行中心

### 3.1 页面数据

- 当前运行中与排队 Run。
- 每个 Run 的实验、代码、数据、阶段、Epoch、指标、GPU、状态和 ETA。
- 两张 GPU 的利用率、显存、温度、功率与占用 Run。
- 最近最佳指标、本周 GPU 时长和最近活动。
- 用户新手清单进度。

### 3.2 操作

- 创建实验：打开共享草稿的分步向导/高级模式。
- 点击 Run：进入 Run 详情。
- 点击 GPU 摘要：打开 GPU 与队列抽屉。
- 隐藏新手清单：保存用户偏好；辅助设置允许重新打开。
- 刷新仅作为手动兜底；运行数据主要通过 SSE 更新。

## 4. 数据

### 4.1 资源浏览

- 支持任意多层用户文件夹；文件夹只组织资产，不决定授权。
- 全局搜索跨文件夹查找 Dataset 与 DatasetVersion。
- 详情包含版本、时间范围、频率、流域数、字段、摘要、血缘和使用记录。

### 4.2 创建数据

三类来源：本地文件/文件夹上传、服务端 URL 下载、从已有版本派生。

统一流程：

```text
创建导入任务 → 上传/下载/复制 → 安全扫描 → 格式探测 → 字段推断
→ 用户确认字段映射 → 生成不可变 DatasetVersion → 可用于实验
```

字段映射至少支持：时间、流域 ID、动态输入、静态属性、目标变量、忽略；保存标准名、单位、顺序、置信度和用户修正。

任何失败不得产生“可用”版本；保留导入任务及错误，可安全重试。

## 5. 模型代码、实验模板和环境

### 5.1 代码导入

来源为 ZIP 或 Git。后端执行解压安全检查、内容摘要、提交锁定和只读快照。Git 凭证不得写入快照或日志。

### 5.2 模板发现

- 优先解析 `hydro-experiment.yaml`。
- 没有清单时扫描入口脚本、参数解析器和 README，生成待确认草稿。
- 模板按 training、evaluation、prediction、plotting 分类命令。
- 模板参数保存类型、默认值、校验、可选值、敏感性和 CLI/config 映射。

### 5.3 环境

环境是独立版本化资产。环境版本保存 Python、CUDA、框架、依赖锁、镜像摘要、构建日志和状态。代码版本可关联多个环境；ExperimentVersion 锁定一个精确环境版本。

## 6. 实验创建与实验详情

### 6.1 Experiment 与 Run

- Experiment：可复用、可版本化的配置定义。
- ExperimentVersion：一次冻结的模板、代码、数据、环境、参数默认值和输出约定。
- Run：基于 ExperimentVersion 的一次执行，可覆盖 seed、允许覆盖的参数、数据版本和环境版本。

### 6.2 共享草稿

分步向导和高级模式使用同一个服务端/前端 Draft Schema；切换不丢字段。草稿包含：代码版本、模板版本、数据版本、模式、初始 Checkpoint、环境版本、参数、资源、输出和进度协议。

### 6.3 动态参数

参数由模板 Schema 生成，可搜索、新增自定义参数、修改类型/值/映射、删除自定义项、恢复默认值和另存为预设。后端必须验证值类型、范围和映射安全；不能直接把未经解析的字符串拼成宿主机命令。

### 6.4 提交

提交先执行兼容性与资源预检；通过后以同一事务创建 Experiment/Version（按操作类型决定）、Run 和队列 Outbox。重复提交由 Idempotency-Key 返回同一结果。

### 6.5 实验详情

展示配置摘要、当前版本和全部 Run 历史；每个 Run 标明相对默认配置的覆盖。失败 Run 显示失败阶段、错误摘要、现场是否完整和可用动作。

## 7. Run 详情与控制

### 7.1 状态机

```text
DRAFT → QUEUED → PREPARING → RUNNING → EVALUATING → PLOTTING
→ UPLOADING → SUCCEEDED
```

任一执行态可进入 FAILED；QUEUED/执行态可在授权后进入 CANCELLING → CANCELLED。终态不可回退。

### 7.2 实时数据

SSE 推送状态、阶段、Epoch、Batch、指标、ETA、日志游标和资源采样。断线后客户端用 `Last-Event-ID` 续接；详情初次加载通过 REST 获取快照。

### 7.3 控制

- 停止：幂等，先请求优雅停止，再超时强制终止。
- 重新运行：创建新 Run，不重置旧 Run。
- 从失败阶段重试：仅当阶段产物完整、模板声明阶段可重入且输入哈希未变化时开放；否则只能复制配置。
- 失败/取消后保留 resolved config、日志、错误、已生成产物和资源释放记录。

用户拖拽布局属于用户偏好，不属于 Run 业务数据，可存浏览器并逐步迁移到用户设置接口。

## 8. Checkpoint

详情展示来源 Run/ExperimentVersion、代码/环境版本、架构签名、state_dict 摘要、输入输出、Scaler、优化器/Scheduler、指标、对象摘要和派生 Run。

统一复用模式：resume、finetune、evaluate、predict。

兼容性状态：

```text
COMPATIBLE | PARTIAL_LOAD | MAPPING_REQUIRED | INCOMPATIBLE
```

检查代码/架构签名、state_dict 键与形状、输入变量及顺序、输出维度、频率和 Scaler。存在差异时必须提交显式修复方案；后端重新校验并把最终方案写入 Run provenance，禁止静默忽略。

## 9. 结果与对比

### 9.1 结果索引

只列出已产生可用结果的 Run。支持按实验、Run、模型、数据版本、状态、时间搜索筛选；按 NSE/KGE/RMSE/完成时间排序。选择 2–5 个结果前，服务端检查任务类型、指标 Schema、时间范围和流域维度。

### 9.2 单次结果

- 总览：全局指标、自动摘要和标准图。
- 逐流域：流域指标、分布和诊断入口。
- 结果资产：预测、指标、图表、Checkpoint、配置、报告和下载。

摘要必须基于结构化规则并标记证据，不输出未经验证的因果结论。

### 9.3 流域与事件诊断

综合诊断展示过程线、散点、残差、数据质量；事件模式展示洪峰误差、峰现偏差和洪量误差。所有结论标记为计算证据。

### 9.4 绘图

结构化配置和自然语言共用 PlotSpec。自然语言先转换为可审阅结构化计划，确认后才执行。每张图保存 PNG/SVG、源数据切片、PlotSpec、脚本、源 Run 和文件哈希。

### 9.5 导出

用户选择文件或预设后创建异步导出任务。下载包包含 manifest、文件哈希和来源；服务端生成短期下载地址，不代理超大文件内容。

### 9.6 多 Run 对比

四区：指标表、相对基线参数差异、多 Run 过程线、逐流域差异。对比本身可先按请求即时计算，若需要长期保存再引入 Comparison 实体。

## 10. 权限与环境管理

权限与分享页聚合当前用户创建的只读链接，支持筛选、复制、撤销和查看访问统计。运行环境页展示环境版本、构建状态、镜像摘要和使用情况；创建环境触发独立受限构建任务，不能在 API 容器内构建。

## 11. 前端接入要求

后端接入时不直接在单体 `App.tsx` 中散落 fetch。先拆出：

```text
src/api/          # OpenAPI 生成或手写类型安全客户端
src/features/     # dashboard, datasets, code, experiments, runs, checkpoints, results
src/mocks/        # 显式 Mock adapter，仅开发环境
src/types/        # UI 派生类型，不复制后端 Schema
```

每个页面按 `Mock adapter → API adapter` 替换，保持同一 ViewModel。生产构建禁止启用 Mock。

## 12. 原型验收保持项

- 六个主入口与两个辅助入口不变。
- Experiment 与 Run 不混用。
- 结果先列表，再单次详情或多 Run 对比。
- Checkpoint 不兼容时必须阻止提交并要求修复。
- 失败 Run 必须保留现场。
- 分享只读、版本锁定且可撤销。
- GPU 保持紧凑摘要加抽屉，不扩成独立主页面。
